## Unlocked Combinations

Sorting now combines with earlier arrays, strings, maps, and sets because all required state has been introduced. The released combination has its own lesson and staircase rather than appearing as an unexplained exercise.

### Teach Now

Strings with maps and sorting is released in Lesson 09. String traversal supplies characters, sorting creates a canonical signature, and a map groups original strings by that signature. The lesson distinguishes a true equality signature from frequency-based output ordering and from the weaker frequency-multiset condition used by close strings.

### Already Covered

Arrays with sorting appears throughout the chapter. Sort-and-sweep uses an ordered frontier, sort-and-deduplicate compresses equality runs, and sort-then-scan retains a local summary. These are linked families rather than new combination lessons because their complete staircases already live in Lessons 06 through 08.

### Deferred

Sorting with two pointers waits for Chapter 08, where pointer movement and duplicate policy are taught. Interval sorting waits for Chapter 10, where endpoint semantics and overlap ownership become explicit. Sorting with greedy choice also remains deferred until the greedy chapter proves why the locally selected item is safe. No exercise in this chapter silently requires those unreleased invariants.
